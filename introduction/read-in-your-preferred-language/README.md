# Read in Your Preferred language

### Read These Pages In The Language You Understand Best

Before you start reading, As you opened the link in your browser.

If English is not the language you understand best, use the browser translation tool.

The goal is not to struggle through English.

The goal is to understand the lessons.

#### iPhone

Open the Book link in Safari.

Tap the **aA** button in the address bar.

Tap Translate Website.

Choose the language you understand best.

#### Android

Open the Book link in Chrome.

Tap the three dots ... in the top-right corner.

Tap Translate.

Choose the language you understand best.

Read this book in the language that reaches you clearly.
